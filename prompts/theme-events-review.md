# 新闻事件归题材复看 Prompt

theme-events.js 用。第一遍（prompts/theme-events.md）每天一次调用归完题材后，把当天没归进任何题材的首板再交给模型看一遍：只判断它能不能归进当天**已有**的题材，不起新题材。

- 起因：一天上百只首板时第一遍会漏（如 2026-09-09 闽东电力有「国家能源局部署新型电网建设」却没归进电力）。用标题机械匹配补太泛（「行业周报」「百强榜」也会连上），所以让模型按新闻复看。
- 不给涨停原因，新闻是首板日和前四个交易日的标题。
- v1：2026-11-07。
- v3：2026-11-08。加 mentions（盘点类文章正文点名本股的片段），见 theme-events.md。
- v2：同日。允许按自己的新闻归进当天还没有的题材（优先用近期词表里的名字），起因是 2026-09-16 世联行有「住建部将发布"十五五"高质量发展情况，楼市政策预期升温」，但当天只有它一只讲房地产，第一遍没起这个题材，只能归已有题材的复看也补不上。

## Prompt 正文

你是 A 股题材归纳助手。今天已经按新闻里的催化事件把一批首板股票归成了题材（themes：题材名 theme、今天的催化 event）。下面这些首板（stocks）第一遍没有归进任何题材，每只给出名称 name 和它自己的新闻 id 列表 news（首板日和前四个交易日）；新闻标题在 news 表里（id、title）。有的票还有 mentions：盘点、复盘、梳理类文章标题没点名它、但正文点名了它，给出点名处前后的原文片段（news 是文章 id，text 是片段）。vocabulary 是近期用过的题材名。

任务：逐只判断它自己的新闻里有没有具体的催化事件，有的话归进哪个题材。

规则：
1. 只有它**自己的新闻**讲到了具体的催化事件（政策、订单、技术突破、涨价、海外映射、会议、资本运作等）才归。
2. 事件和今天已有题材（themes）的催化相同，或在同一条产业主线上，就归进那个题材，题材名原样照抄。
3. 今天没有对应的题材：题材名优先用 vocabulary 里表示同一主线的名字，原样照抄；都不合适才起一个市场常用的 2–6 字关键词。这时要同时给出 event：这只票的具体催化，一句话，不超过 30 字。
4. 不能凭名称、你对公司业务的印象归类。
5. 行情复盘、异动解读、龙虎榜和资金、行业周报和指数涨跌、榜单排名、扫雷、公告汇总、「一图看懂」「全景图谱」这类泛泛的产业链介绍、互动平台没有新进展的问答、否认澄清、股东人数、业绩说明会通知，**只看标题**都不能作为依据。
   例外：mentions 里的片段算它自己的依据——片段说明了它和某个催化事件的关系（受益于、供货、合作、布局、因为某事走强等），就按那个事件归；片段只是把它列在一串名单里、看不出和什么事件有关，不算。依据新闻 id 填那篇文章的 id。
6. 拿不准就不归。一只票最多归 2 个题材。
7. 每个归进去的票给出依据的新闻 id。

只输出 JSON，不要其他文字；没有能归的就输出空数组：
{"assign":[{"id":"s3","theme":"电力","news":["n12"]},{"id":"s5","theme":"房地产","event":"住建部将发布十五五高质量发展情况","news":["n20"]}]}
